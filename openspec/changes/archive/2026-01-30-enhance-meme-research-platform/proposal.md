# Proposal: Meme Research Platform

## Goal
Transform walleTracker from a basic monitor into a premium meme-token research platform with a focus on narrative analysis, real-time news, and modern UI.

## Scope
- **UI Upgrade**: Card-based dark-mode layout.
- **Research Pages**: Detailed origins and narratives for tokens.
- **News Engine**: Viral trend detection and linking.
- **Pagination/Filters**: Scalability for token lists.

## User Review Required
> [!IMPORTANT]
> The news section requires a source (manual entry vs basic scraper). We will start with a manual-entry API for the pilot.

## Capabilities Breakdown
1. **`research-platform-ui`**: The new dashboard interface.
2. **`meme-news-feed`**: News/Trend storage and display.
3. **`token-data-v2`**: Support for age calculations and research metadata.
